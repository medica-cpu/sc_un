# Мой уход — Panasonic EH-SR90 + ReadySkin nanoSkin

## Что это

**Сборка:** PWA v28 (обновление от v23).

Отдельная копия PWA, в которой можно выбирать активный аппарат:
- Panasonic VITALIFT EH-SR90;
- ReadySkin nanoSkin.

При выборе аппарата приложение переключает недельный план, пошаговые процедуры, список косметических средств, видео, фотосхемы и раздел «Очистка». Остальные функции сохранены: календарь, история, частичный процент выполнения, заметки, цель, напоминания, звуковой сигнал таймера, резервное копирование.

Отметки процедур и заметки хранятся раздельно по аппаратам, чтобы история EH-SR90 и nanoSkin не смешивалась. Данные из v23 автоматически сохраняются; для прежних заметок без маркировки прибора будет выбран активный при обновлении аппарат. Расписание и названия средств каждого аппарата тоже сохраняются отдельно.

## Программа ReadySkin nanoSkin

### Стартовый этап — первые 2 недели

Приложение устанавливает следующий график:
- Понедельник — Cleansing, 3 минуты.
- Вторник — восстановление.
- Среда — Nourishing, 3 минуты.
- Четверг — восстановление.
- Пятница — RF, 3 минуты.
- Суббота — восстановление.
- Воскресенье — Massaging, 3 минуты, затем Cool, 3 минуты.

Распределение по дням — удобный шаблон на основе частоты из таблицы руководства; конкретные дни недели производителем не назначены. Для первых двух недель в руководстве указана частота по одному разу в неделю для RF, Cleansing, Nourishing и Massaging. Начинать рекомендуется с минимального уровня мощности 1.

Cool — отдельный завершающий режим. В стартовом шаблоне он включён один раз после воскресного Massaging. Если несколько режимов объединяются в один сеанс, Cool выполняется только один раз после последнего режима, а не после каждого режима внутри комбинации.

### Следующие этапы курса по руководству

После первых двух недель в руководстве указана основная фаза продолжительностью 4 недели:
- RF — 3 раза в неделю;
- Cleansing — 2 раза в неделю;
- Nourishing — 2 раза в неделю;
- Massaging — 3 раза в неделю.

Поддерживающий этап продолжительностью 4 недели:
- Cleansing и Nourishing — по 1 разу в неделю;
- RF и Massaging — по 1 разу в 2 недели.

Текущая версия программы настроена на стартовый двухнедельный этап. Частота не увеличивается автоматически. Перед переходом к следующей фазе сверяйся с полной таблицей курса в руководстве.

### Подготовка и средства по режимам

- **Cleansing:** снять макияж и загрязнения, не вытирать кожу насухо; снять фиксирующее кольцо, закрепить нетканую салфетку и пропитать её водным очищающим средством (например, мицеллярной водой или лосьоном). Не заменять его контактным гелем.
- **Nourishing:** нанести на кожу уходовое средство, подходящее для электропорации (сыворотку, эссенцию или крем), затем поверх него — контактный гель.
- **RF:** использовать контактный гель; на старте уровень мощности 1.
- **Massaging:** режим RF + электростимуляции; использовать контактный гель, на старте уровень мощности 1. В пошаговой инструкции приведены шесть направлений движений для лица из руководства.
- **Cool:** выполнять в конце сеанса; дополнительные косметические средства не нужны.

Каждый режим рассчитан примерно на 3 минуты. Следуй руководству прибора, держи рабочую поверхность в контакте с кожей и не задерживай её неподвижно на одном месте.

## Важные ограничения ReadySkin nanoSkin

В руководстве перечислены противопоказания, включая беременность и лактацию, острые инфекционные/вирусные заболевания, онкологические и психические заболевания, кардиостимулятор, некоторые заболевания кожи и соединительной ткани, острые воспаления и гнойные процессы, обострение дерматита/дерматоза или акне, купероз в зоне воздействия, склонность к келоидам, некоторые имплантаты, тяжёлый диабет, тяжёлую гипертонию и нарушения сердечного ритма, приём дерматотропных препаратов, грипп/ОРВИ/повышенную температуру и активный загар. Это не полный список — проверь руководство целиком.

Во время процедуры необходимо избегать глаз, области сердца, щитовидной железы и половых органов. У ReadySkin nanoSkin нет отдельного режима EYE CARE; приложение не предлагает обработку области вокруг глаз.

При появлении дискомфорта прекрати процедуру. Если прибор нагрелся после интенсивной работы, руководство рекомендует дать ему остыть не менее 30 минут, отключив от зарядного устройства.

## Раздел «Техника»

Для nanoSkin добавлена официальная видеоинструкция ReadySkin с переходами к главам:
- RF — 1:15;
- Cleansing — 2:01;
- Nourishing — 3:01;
- Massaging — 4:02;
- Cool — 5:13.

В разделе «Техника» для RF и Massaging добавлена встроенная оригинальная страница 26 актуальной инструкции ReadySkin nanoSkin — все шесть фирменных рисунков на одном листе; есть прямая ссылка «Открыть оригинальную страницу 26 в PDF». Для каждого направления также оставлены шесть отдельные локальные векторные перерисовки по странице 26, чтобы можно было пользоваться подсказками офлайн. Локальные перерисовки не являются точными копиями файлов производителя. Оригинальная страница загружается онлайн (iOS может открыть PDF во внешнем просмотрщике).

## Раздел «Очистка» для ReadySkin nanoSkin

В отличие от Panasonic, nanoSkin нельзя мыть в воде. Его инструкция по очистке заменена на отдельные шаги:
1. Выключить прибор и очистить головку/электроды от остатков геля мягкой тканью.
2. Магнитное кольцо и терморегулятор протирать хлопчатобумажной или мягкой тканью. Не тереть сильно и не нажимать.
3. Не мой прибор в воде.

Иллюстрации для nanoSkin в этой копии — схематические изображения, подготовленные для приложения. Текст инструкций основан на руководстве производителя.

## Как установить на GitHub Pages с Windows

1. Создай отдельный репозиторий GitHub для версии с двумя аппаратами либо замени файлы в существующем репозитории, если хочешь обновить прежнюю установку.
2. Загрузи все файлы из этой папки и всю папку `assets`.
3. В Settings → Pages выбери Deploy from a branch, `main`, папку `/ (root)`, затем Save.
4. Открой опубликованный HTTPS-адрес на iPhone в Safari и добавь на главный экран.
5. Открой PWA один раз онлайн, чтобы Service Worker загрузил файлы в кэш.

Для копии используется отдельный ключ localStorage `ehsr90-readyskin-dual-v1`, чтобы она не перезаписывала данные прежнего Panasonic-приложения даже при публикации на том же домене GitHub Pages. При первом запуске на том же origin приложение однократно читает старый ключ `ehsr90-planner-v2` и переносит Panasonic-план, отметки, заметки, цель и настройки в новое изолированное хранилище. Старое приложение остаётся нетронутым. Если новая копия публикуется на другом origin, перенеси резервную копию через раздел «Данные приложения».

## Уведомления

Изменение времени в приложении изменяет время при следующем экспорте файла календаря `.ics`. Уже импортированные события Apple Calendar автоматически не изменяются. Для надёжных напоминаний, когда PWA закрыто, импортируй обновлённый `.ics` в календарь iPhone.

## Конфиденциальность и ограничения

Данные хранятся локально в браузере. История и отметки разделяются по выбранному аппарату. Видео требуют интернет; схемы и инструкции кэшируются для офлайн-доступа после первого запуска. Приложение не подключается к прибору и не является медицинским устройством или официальным приложением Panasonic/ReadySkin.
